WEBTE1 — робочі інструкції під час пісомки

Відкрий цей файл разом із умовою. Почни з наданого HTML, потім шукай потрібну дію через Cmd+F у Sources: готові блоки коду. Якщо завдання стосується витягування даних, йди за порядком HTML-парсингу або відкрий простий робочий приклад Z2 Eat & Meet. Усе працює без зовнішніх бібліотек і шрифтів.

Перші 5 хвилин

  1. Прочитай умову й познач: які дані витягти, що показати, які кнопки/фільтри, що має змінюватися на мобільному.
  2. Відкрий виданий HTML. Знайди повторюваний зовнішній блок і поля всередині нього. Запиши точні селектори.
  3. Визнач джерело: дані в поточному документі → document; потрібно завантажити HTML → fetch за реальною URL-адресою.
  4. Перевір у Console кількість знайдених блоків. Якщо 0 — виправ селектор до написання решти коду.
  5. Спочатку зроби масив об’єктів і console.table. Тільки після цього пиши відображення та CSS.

Який шлях використовувати

На твоєму скрині FileZilla видно /public_html із папками Z2_postaichuk та cvicenie2–cvicenie8. Це шлях на сервері. Браузер і fetch працюють із URL-адресами. Не пиши у коді fetch("/public_html/...").

Що реально далиДія
Дані вже в цьому HTMLconst doc = document; — можна відразу шукати елементи.
Потрібно завантажити цей самий HTML, як у Z2fetch(location.pathname), потім response.text() і DOMParser.
Дали окремий HTML-файлВізьми його точну браузерну адресу з умови або відкрий файл у браузері й скопіюй URL. Перевір HTTP 200 у Network.

Якщо відкрив сторінку через file:// і fetch не працює, запусти її через локальний сервер WebStorm або шкільний сервер. Для локального HTML інтернет не потрібен.

Як тримати довідник доступним на шкільному сервері

У FileZilla передай усю папку webte1-help в окрему папку всередині /public_html, яку можеш створити або до якої маєш доступ. Збережи файли разом і відкривай index.html через браузер; тоді посилання й Z2-приклад працюватимуть. Не клади довідник усередину cvicenie8/dist, щоб не змішувати його зі збіркою вправи.

Відкрий сторінку через браузер і перевір посилання на Sources та гайд. Файли довідника не завантажують нічого з інтернету.

Перед здачею

  • У Console немає несподіваних помилок; Network показує правильні URL і HTTP-статуси.
  • Перевірені всі кнопки й фільтри, порожній стан та повторне натискання.
  • На ширині близько 375 px немає горизонтальної прокрутки.
  • Усі підключені CSS/JS-файли лежать там, де їх шукає HTML. Немає CDN або залежності від інтернету.

Додаткові автономні приклади коду: Grid, hover і мобільний порядок · JSON та пауза анімації. Вони ілюструють окремі механіки; актуальні селектори та вимоги завжди бери з виданого завдання.
